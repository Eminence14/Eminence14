# Hi 👋 I'm Victor Ibidunmoye

## Mechanical & Product Design Engineer

I design machines that take work off people's hands. A pounder that saves hours of pounding by arm. A pump that lifts water where there's no electricity. A grinder that runs on gravity.

They have to survive where the grid doesn't, and a local workshop has to be able to build them. So every design goes all the way through to assemblies, tolerances and GD&T in SolidWorks, because a drawing that can't be made solves nothing.

Previously a web developer. Most of the repos here are from those years, and I still write the code behind my own work: my portfolio is a single hand-written HTML file, no framework, no build step. Same instinct, different material.
